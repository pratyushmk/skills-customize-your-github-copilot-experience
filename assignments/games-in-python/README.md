
# Hangman Game Challenge

## Overview

Build a Hangman game in Python that uses strings, loops, and user input to let a player guess a hidden word.

## What to Build

Create a game that:
- selects a secret word from a predefined list
- accepts letter guesses from the player
- shows game progress in `_ _ _` format
- tracks remaining incorrect guesses
- ends when the word is guessed or attempts run out
- displays a win or lose message

## Requirements

Your solution must:
- randomly select a word from a predefined list
- accept letter guesses and update the display
- show current progress with blank placeholders
- count and limit incorrect guesses
- end the game on win or loss
- display a final result message

## Submission

Write your Hangman game in Python in a single file. Keep the game loop, input/output, and word selection together, and make sure the player can follow the game progress clearly.
